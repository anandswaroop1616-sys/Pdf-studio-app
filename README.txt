PDF Studio – install on your phone
1. Upload ALL files in this folder to any free HTTPS host:
   - Netlify Drop: app.netlify.com/drop (drag the folder in)
   - or GitHub Pages / Cloudflare Pages
2. Open the https:// link in Chrome on Android.
3. Menu (⋮) > "Install app" / "Add to Home screen".
4. Optional real APK: go to pwabuilder.com, paste your link, choose Android > Download.
